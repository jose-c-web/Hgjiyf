# Integration gates

1. Allocate ten unused Quetzal flags and replace the placeholder IDs.
2. Resolve actual Sinnoh map IDs from the ROM's map-header layer.
3. Attach each script to the correct ObjectEvent or CoordEvent.
4. Add Sinnoh text resources and verify pointers.
5. Compile and run from Twinleaf through the first gym, then extend to all eight gyms, League, Champion and post-game.

No runtime claim is made before emulator verification.
