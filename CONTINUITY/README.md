# Sinnoh GBA Continuity Package

Canonical handoff for continuing the Sinnoh GBA ROM-hack without restarting prior phases.

Start with:
1. `SINNOH_CONTINUITY_PHASE44.md`
2. `PROMPT_PROXIMO_CHAT_SINNOH_SCRIPTS.md`
3. `CONTINUITY/PHASE44/RECOVERY_MANIFEST.md`
4. `CONTINUITY/PHASE45/STATUS.md`

Phase 44 is the event-conversion checkpoint. Phase 45 is script conversion.

Do not replace Phase 44 with Phase 43, Step 21, or another earlier ROM merely because it is available.
